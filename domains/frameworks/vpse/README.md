# frameworks/vpse — Velaris Predictive Scenario Engine

Predictive scenario planning framework. VPSE agents build, model, and evaluate future scenarios to support strategic decision making under uncertainty.

| Agent | Description |
|-------|-------------|
| VPSE_CORE | Core scenario engine — manages scenario lifecycle and evaluation |
| VPSE_MODELER | Builds quantitative models for each scenario |
| VPSE_SCENARIO | Defines and parameterises individual scenarios |
