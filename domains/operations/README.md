# operations

Operational execution layer — business autopilot, process automation, scheduling, logistics coordination, feasibility assessment, and system telemetry. Also serves as the catchall domain for agents not assigned to a specialist domain.

## Agents

| Agent | Description |
|-------|-------------|
| BUSINESS_AUTOPILOT | End-to-end business process automation — runs recurring workflows autonomously |
| OPERATUS | Operations orchestrator — coordinates cross-functional operational tasks |
| OPTIMA | Optimisation engine — finds and applies efficiency improvements across processes |
| POLARIS | Directional anchor — keeps operational decisions aligned with strategic goals |
| FEASIBILITY_ENGINE | Assesses feasibility of plans, projects, and initiatives before execution |
| INITIATIVE_ENGINE | Launches and tracks strategic initiatives from ideation to outcome |
| SAGE | Wisdom layer — applies historical patterns and lessons to current decisions |
| FABRICA | Manufacturing and production operations coordinator |
| HELIX | Iterative improvement loop — continuous process refinement and learning |
| GENEFLOW | Workflow genetics — evolves and mutates process flows for better performance |
| FLUXOR | Flux management — handles rapid change and volatility in operational state |
| NIRVANA | Steady-state optimiser — drives operations toward low-noise, high-efficiency equilibrium |
| SANDE | Sand-and-deliver executor — breaks large tasks into deliverable micro-chunks |
| CONVERGENCE_BRIDGE | Bridges divergent sub-processes back to unified operational outcomes |
| HYPERSYNC | High-frequency synchronisation across parallel operational threads |
| TACTICIAN | Tactical execution planner — short-horizon action sequencing |
| DYNAMICA | Dynamic adaptation engine — real-time operational pivots based on signals |
| VELOCITY_LOOP | Acceleration loop — identifies and removes friction from core workflows |
| AGENT_LIFECYCLE | Manages the full lifecycle of agents — spawn, suspend, retire |
| AGENT_LIFECYCLE_MANAGER | Supervisor for AGENT_LIFECYCLE — policy and escalation handling |
| CCSF_CORE | Cross-Context Synthesis Framework core — merges signals across operational contexts |
| CCSF_FUSION | CCSF fusion layer — integrates heterogeneous data streams into coherent state |
| CCSF_RESOLVER | CCSF conflict resolver — handles contradictions between context signals |
| CORE_CONVERGENCE | Convergence point for all core operational signals before action |
| EOF_CORE | End-of-Flow core — manages terminal states and handoff protocols |
| EOF_GATEWAY | Gateway agent for end-of-flow transitions between pipeline stages |
| EOF_POLICY | Policy enforcement at end-of-flow boundaries |
| PERSONALITY_MOD | Modulates agent communication personality to match organisational culture |
| POLICY_CONTROLLER | Operational policy controller — enforces rules across all running processes |
| STRATEGOS | Strategic operations agent — links strategy to execution at the ops layer |
| SYSTEM_TELEMETRY | Collects and exposes real-time system health and performance telemetry |
