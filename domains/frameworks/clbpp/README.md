# frameworks/clbpp — Cognitive Load Balancing and Predictive Processing

Cognitive load management framework. CLBPP agents monitor agent cognitive load, distribute it across available capacity, and predict overload before it occurs.

| Agent | Description |
|-------|-------------|
| CLBPP_CORE | Core load balancing runtime |
| CLBPP_DISTRIBUTOR | Distributes cognitive tasks across agents to equalise load |
| CLBPP_OVERLOAD_MONITOR | Detects and alerts on cognitive overload conditions |
| CLBPP_PREDICTIVE_BALANCER | Predicts future load and pre-positions capacity |
| COGNITIVE_LOAD_BALANCER | Master balancer — top-level cognitive resource allocation |
