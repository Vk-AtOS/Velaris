# self_management

Self-awareness and introspection layer — consistency checking, self-correction, identity maintenance, and contextual self-modelling for the BOS as a whole.

## Agents

| Agent | Description |
|-------|-------------|
| SELF_CONSISTENCY | Validates that agent outputs are internally consistent across time and context |
| SELF_CORRECTION_ENGINE | Detects and corrects agent errors before they propagate downstream |
| SELF_HISTORY | Maintains a structured history of the system's own decisions and outcomes |
| SELF_IDENTITY | Anchors the system's operational identity — who it is, what it stands for |
| CONTEXTUAL_SELF_MODEL | Builds and updates a dynamic model of the system's own capabilities and state |
