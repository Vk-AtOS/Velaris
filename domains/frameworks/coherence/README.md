# frameworks/coherence — Coherence and Synchronisation Suite

System-wide coherence, synchronisation, and inter-agent alignment framework. These agents ensure that all agents maintain consistent state, aligned reasoning, and coherent behaviour across the full mesh.

| Agent | Description |
|-------|-------------|
| COHERENCE_SYNC_CORE | Master coherence synchroniser — coordinates state alignment across all agents |
| INTER_AGENT_COHESION | Enforces cohesion protocols between collaborating agents |
| CSG_STATEALIGN | Coherent State Graph state alignment — synchronises distributed state graphs |
| CSG_TEMPORAL | Temporal coherence for CSG — ensures consistent time-ordering of state events |
| CSM_CORE | Coherent State Machine core — drives coherent state transitions |
| CSM_LINKER | Links coherent state machines across agent boundaries |
| CSM_POLICY | Policy layer for CSM — governs allowed state transitions |
| CSM_REASONER | Reasons about state machine consistency and detects violations |
| MRF_EVAL | Multi-Resolution Framework evaluator — assesses coherence at multiple scales |
| MRF_REFLECT | MRF reflective layer — self-assessment of coherence quality |
| RCI_CONTEXT | Reflective Coherence Interface context manager |
| RCI_CORE | RCI core runtime — reflective coherence checking |
| RCI_STREAM | Stream-mode RCI — continuous coherence monitoring for live data flows |
| FSCL | Full-System Coherence Layer — top-level coherence enforcement across all domains |
| GCK | Global Coherence Kernel — kernel-level coherence primitives |
| CODEX | Codex of coherence rules — canonical reference for all coherence policies |
