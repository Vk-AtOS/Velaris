# cognition

Advanced reasoning and planning layer — recursive goal decomposition, causal inference, decision graph construction, and meta-level reasoning for complex problem solving.

## Agents

| Agent | Description |
|-------|-------------|
| RECURSIVE_GOAL_PLANNER | Decomposes high-level goals into executable sub-goal trees recursively |
| SELF_DIRECTED_TASKER | Autonomously selects and sequences tasks toward a defined objective |
| DECISION_COLLAPSE_ENGINE | Collapses decision spaces — reduces option sets to the highest-value choices |
| DECISION_GRAPH_ENGINE | Builds and traverses decision graphs for multi-step problem resolution |
| HYPER_REASONER | High-capacity reasoning engine — handles complex multi-variable inference |
| HYPERSTATE_SYNTHESIZER | Synthesises hyperstate representations from partial and noisy inputs |
| CAUSALITY_RESOLVER | Resolves causal chains — distinguishes correlation from causation in data |
| INTENT_SYNTHESIZER | Infers and synthesises agent intent from context, history, and goals |
| META_REASONING_CORE | Reasons about reasoning — self-evaluation and strategy selection |
| META_REINFORCEMENT_CORE | Applies meta-reinforcement learning — learns how to learn from experience |
