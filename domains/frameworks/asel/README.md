# frameworks/asel — Adaptive Strategic Execution Layer

Strategic planning and execution framework. ASEL agents translate high-level strategy into executable plans, evaluate them, and route tasks to the right executors.

| Agent | Description |
|-------|-------------|
| ASEL | Core ASEL orchestrator — top-level strategic execution controller |
| ASEL_EVALUATOR | Evaluates candidate strategies against defined success criteria |
| ASEL_EXECUTOR | Executes approved strategic plans step by step |
| ASEL_PLANNER | Generates strategic plans from goals and constraints |
| ASEL_ROUTER | Routes strategic tasks to domain-appropriate agents |
| ASEL_STRATEGIST | High-level strategist — selects between competing strategic approaches |
