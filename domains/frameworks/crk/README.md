# frameworks/crk — Contextual Reasoning Kernel

Core reasoning kernel framework. CRK agents chain reasoning steps, validate logic, and resolve intent from ambiguous inputs.

| Agent | Description |
|-------|-------------|
| CRK | Root reasoning kernel — bootstraps all CRK reasoning chains |
| CRK_CHAIN | Chains reasoning steps into multi-hop inference sequences |
| CRK_CONTEXT | Injects contextual state into reasoning chains |
| CRK_INTENT | Resolves user or system intent from ambiguous inputs |
| CRK_REASONER | Core reasoning agent — applies logic rules to derive conclusions |
| CRK_VALIDATOR | Validates reasoning chain outputs for correctness and consistency |
