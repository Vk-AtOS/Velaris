# security

Zero-trust security, continuous audit, and threat detection layer. These agents enforce access control, monitor for anomalies, and maintain an auditable record of every action in the system.

## Agents

| Agent | Description |
|-------|-------------|
| VIGILIS | Continuous surveillance agent — monitors all system events in real time |
| ZERO_TRUST_PIPELINE | Enforces zero-trust verification on every inter-agent data flow |
| SENTINELDNA | Behavioural fingerprinting — detects identity drift and impersonation |
| CUSTOS | Guardian of secrets — manages credentials, keys, and sensitive data access |
| PRAETOR | Policy enforcement engine — blocks actions that violate security rules |
| AEGIS | Defensive shield — absorbs and isolates anomalous agent behaviour |
| ARGUS | Multi-eye monitoring — parallel watchdog across all domain boundaries |
| AUDITOR | Immutable audit trail — writes tamper-evident logs of all system actions |
| OVERWATCH | High-level supervisor — triggers escalations when lower guards fail |
| OVERSIGHT_MONITOR | Regulatory oversight companion — tracks compliance posture continuously |
| DECISION_FIREWALL | Intercepts and validates every agent decision before execution |
| SANITY_VERIFIER | Reality-checks outputs — catches hallucinated or malformed agent responses |
| SELF_AUDIT | Reflexive audit agent — audits the security agents themselves |
