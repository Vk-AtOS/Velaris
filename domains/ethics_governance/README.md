# ethics_governance

Policy enforcement and ethical alignment layer. These agents ensure every decision made by the BOS is consistent with the organisation's values, regulatory obligations, and human oversight requirements.

## Agents

| Agent | Description |
|-------|-------------|
| ETHICAL_ENGINE | Core ethical assessment — scores agent outputs against defined value frameworks |
| GOVERNANCE_KERNEL | Central policy store and rule enforcement for organisational governance |
| GOVERNANCE_ADAPTATION_LOOP | Continuously updates governance rules as the environment changes |
| EACPE_ALIGNMENT | Ethical Alignment, Compliance, and Policy Engine — alignment scoring |
| EACPE_HUMAN_GUARD | Human-in-the-loop gate — escalates ethically ambiguous decisions for review |
| EACPE_PROTOCOL | Protocol definitions for EACPE suite — shared contracts and schemas |
