# frameworks/eac — Ethical Audit and Compliance

Ethical audit and compliance framework. EAC agents provide structured audit trails, compliance checks, and ethical governance enforcement across all agent actions.

| Agent | Description |
|-------|-------------|
| EAC_AUDIT | Generates immutable ethical audit records for every governed action |
| EAC_COMPLIANCE | Checks actions against regulatory and policy compliance rules |
| EAC_CORE | Core EAC runtime — audit lifecycle and compliance evaluation |
