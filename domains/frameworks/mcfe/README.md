# frameworks/mcfe — Multi-Context Field Engine

Multi-context field generation and classification framework. MCFE agents classify inputs across multiple contextual fields and generate structured field representations for downstream agents.

| Agent | Description |
|-------|-------------|
| MCFE_CLASSIFIER | Classifies inputs into appropriate contextual field categories |
| MCFE_CORE | Core MCFE runtime and field registry |
| MCFE_FIELDGEN | Generates contextual field definitions from raw data |
| MCFE_ROUTER | Routes classified fields to the correct downstream agents |
