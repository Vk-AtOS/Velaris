# frameworks/mpc — Multi-Perspective Core

Multi-perspective synthesis framework. MPC agents preprocess inputs, fuse multiple analytical perspectives, and deliver unified outputs to decision-making agents.

| Agent | Description |
|-------|-------------|
| MPC_CORE | Core multi-perspective runtime and fusion controller |
| MPC_FUSION | Fuses outputs from multiple perspectives into a single coherent view |
| MPC_PREPROC | Preprocesses raw inputs before perspective analysis |
