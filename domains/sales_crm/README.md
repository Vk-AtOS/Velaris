# sales_crm

Sales intelligence and CRM layer — lead conversion, churn prevention, customer targeting, pipeline management, and domain/market expansion.

## Agents

| Agent | Description |
|-------|-------------|
| CONVERTA | Lead conversion engine — scores, nurtures, and converts pipeline opportunities |
| RETENTA | Customer retention — churn prediction, intervention triggers, loyalty programmes |
| ATTRACTA | Inbound attraction — SEO, content signals, and top-of-funnel demand generation |
| TARGETA | Precision targeting — ICP definition, account selection, and segmentation |
| COHORTUS | Cohort analysis — groups customers by behaviour for lifecycle and LTV analysis |
| AMPLIFEX | Amplification engine — referral loops, viral mechanics, and social proof automation |
| LOGISTA | Logistics for sales — order tracking, fulfilment coordination, SLA management |
| DOMAIN_ADVISOR | Advises on which market domains to prioritise for expansion |
| DOMAIN_EXPANSION | Executes domain expansion plans — new geographies, verticals, segments |
| DOMAIN_MASTERY | Tracks depth of penetration and authority in each active domain |
| DOMAIN_REFINER | Refines domain strategy based on performance signals and competitive shifts |
| DOMAIN_SCOUT | Scouts new potential domains — early-signal detection before full expansion |
