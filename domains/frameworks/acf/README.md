# frameworks/acf — Adaptive Context Framework

Cross-domain context management framework. ACF agents build, route, and fuse contextual state across agent boundaries so every agent operates with full situational awareness.

| Agent | Description |
|-------|-------------|
| ACF_CONTEXT | Manages active context objects — builds and expires context windows |
| ACF_CORE | Core ACF runtime — context lifecycle and storage |
| ACF_FUSION | Fuses context from multiple sources into a single coherent view |
| ACF_ROUTER | Routes context to the correct agent or subsystem |
