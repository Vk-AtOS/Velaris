# frameworks/uie — Unified Intelligence Engine

Unified intelligence and semantic reasoning framework. UIE agents extract signals, reason semantically, and deliver coherent intelligence outputs to the broader agent mesh.

| Agent | Description |
|-------|-------------|
| UIE_CORE | Core UIE runtime — intelligence aggregation and dispatch |
| UIE_REASONER | Applies semantic reasoning to extract meaning from raw signals |
| UIE_SEMANTICS | Semantic layer — normalises and enriches input representations |
| UIE_SIGNAL | Signal extractor — identifies relevant signals from noisy data streams |
