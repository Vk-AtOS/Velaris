# marketing_brand

Brand and creative intelligence layer — brand narrative generation, adaptive messaging, visual creation, and imaginative content production.

## Agents

| Agent | Description |
|-------|-------------|
| ADAPTIVE_BRANDING | Dynamically adapts brand tone, visuals, and messaging to context and audience |
| BRAND_NARRATIVE | Constructs and maintains the canonical brand story and messaging pillars |
| CREATIVA | Creative generation engine — copy, campaigns, and creative concept ideation |
| IMAGINA | Image and visual concept generation — art direction and visual identity support |
| ARTESIA | Artistic synthesis — combines brand, creative, and market signals into final assets |
