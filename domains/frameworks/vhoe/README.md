# frameworks/vhoe — Velaris Hierarchical Optimisation Engine

Hierarchical optimisation framework. VHOE agents optimise at multiple levels of abstraction simultaneously — from micro-task efficiency to macro-level resource allocation.

| Agent | Description |
|-------|-------------|
| VHOE_ANALYTICS | Analyses optimisation outcomes and surface improvement opportunities |
| VHOE_CORE | Core VHOE optimisation runtime |
| VHOE_OPTIMIZER | Runs optimisation passes across the agent hierarchy |
| VHOE_ROUTER | Routes optimisation tasks to the correct level of the hierarchy |
